# Диаграмма Ганта — укрупнённый график производства работ

Интерактивный веб-редактор календарного плана: таблица задач слева и временная шкала справа. Подходит для укрупнённых графиков СМР — группы работ, сроки, объёмы и зависимости между задачами.

Стек: **React 19**, **TypeScript**, **Vite**, **Ant Design**, **dayjs**. Архитектура: **Feature-Sliced Design (FSD)**.

## Возможности

- Иерархия задач (группы → подгруппы → работы) с разворотом / сворачиванием
- Редактирование названия, дат начала и окончания, произвольных колонок (ед. изм., кол-во и др.)
- Зависимости между задачами (режим «Зависимость»: предшественник → последователь; циклы запрещены)
- Масштаб шкалы (zoom), синхронная прокрутка таблицы и таймлайна, изменяемая ширина панелей
- Настройка видимости и порядка колонок
- Импорт / экспорт JSON, встроенный редактор JSON, drag-and-drop `.json` в окно
- Печать (`window.print`)
- Локаль и подписи интерфейса на русском

## Быстрый старт

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Приложение откроется на адресе, который покажет Vite (обычно `http://localhost:5173`).

### Скрипты

| Команда           | Описание                           |
|-------------------|------------------------------------|
| `npm run dev`     | Режим разработки с HMR             |

## Формат данных

Документ графика — JSON-объект `GanttData` (тип в `entities/task`):

```json
{
  "meta": {
    "title": "Укрупнённый график производства работ",
    "subtitle": "Объект или пояснение"
  },
  "columns": [
    { "id": "c1", "title": "Ед. изм.", "hidden": false },
    { "id": "c2", "title": "Кол-во", "hidden": false }
  ],
  "tasks": [
    {
      "id": "task-1",
      "name": "Название работы",
      "start": "2026-01-12",
      "end": "2026-02-20",
      "fields": ["п.м.", "420", "", "", "", "", "", "", "", ""],
      "collapsed": false,
      "dependsOn": [],
      "children": []
    }
  ]
}
```

| Поле задачи     | Описание                                  |
|-----------------|-------------------------------------------|
| `id`            | Уникальный идентификатор                  |
| `name`          | Название                                  |
| `start` / `end` | Даты в формате `YYYY-MM-DD`               |
| `fields`        | Значения пользовательских колонок (до 10) |
| `dependsOn`     | Массив `id` предшественников              |
| `children`      | Вложенные задачи                          |
| `collapsed`     | Свёрнута ли группа в таблице              |

При импорте данные нормализуются: недостающие поля подставляются значениями по умолчанию.

В проекте есть демо-набор (`src/entities/task/mocks/sample.ts`) — пример графика по станции «Технопарк».

## Структура `src` (FSD)

Импорты идут только вниз по слоям: `app → pages → widgets → features → entities → shared`.  
Слайс экспортирует публичный API через `index.ts`. Алиас `@/*` указывает на `src/*`.

```
src/
├── main.tsx                         # Точка входа: шрифты, стили, render
├── app/
│   ├── App.tsx                      # Корневой shell → страница
│   ├── providers/                   # ConfigProvider (тема, ru_RU)
│   └── styles/index.css             # Глобальные стили
├── pages/
│   └── gantt-page/                  # Состояние документа и оркестрация экрана
├── widgets/
│   ├── gantt-toolbar/               # Панель действий и zoom
│   ├── gantt-workspace/             # Таблица + splitter + таймлайн, sync scroll
│   ├── task-table/                  # Левая таблица
│   └── gantt-timeline/              # Правая шкала (бары, связи, геометрия)
├── features/
│   ├── column-settings/             # Видимость / порядок колонок
│   ├── link-tasks/                  # Режим зависимостей
│   └── import-export/               # Импорт, экспорт, JSON-редактор
├── entities/
│   └── task/                        # GanttData / Task, дерево, normalize, sample
└── shared/
    ├── config/                      # Тема Ant Design, константы раскладки
    ├── lib/dates/                   # Дата-хелперы
    └── ui/splitter/                 # Разделитель панелей
```

## Использование

1. Заголовок и подзаголовок документа редактируются в шапке рабочей области.
2. **+ Группа** / **+ Задача** — добавить элементы верхнего уровня; у строки группы — дочерняя задача.
3. **Зависимость** — включить режим, кликнуть предшественника, затем последователя (повторный выбор той же пары снимает связь). `Esc` отменяет режим.
4. **Колонки** — показать / скрыть фиксированные и пользовательские поля.
5. **Импорт JSON** или перетаскивание файла в окно — загрузить план; **Экспорт** — сохранить текущий документ.
