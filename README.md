# План-график (диаграмма Ганта)

Интерактивный веб-редактор календарного плана в стиле TDMS: таблица слева и временная шкала справа. Подходит для графиков выпуска проектной документации — иерархия карточек, сроки, отделы и зависимости между задачами.

Стек: **React 19**, **TypeScript**, **Vite**, **Ant Design**, **dayjs**, **write-excel-file**. Архитектура: **Feature-Sliced Design (FSD)**.

## Возможности

- Иерархия задач (площадка → объект → стадия → отдел → комплект / задание) с разворотом и сворачиванием
- Цветовая кодировка строк по типу карточки (`kind`: site, object, stage, dept, book, set, assignment)
- Редактирование названия, фактических дат начала и окончания, длительности (считается по датам), произвольных текстовых колонок
- Переключение вида: **Все**, **Только таблица**, **Только диаграмма**
- Выбор периода шкалы (диапазон дат); кнопка обновления сбрасывает период по данным графика
- Шкала по дням / неделям / месяцам в зависимости от длины периода, масштаб (zoom)
- Синхронная прокрутка таблицы и таймлайна, одинаковая высота строк, изменяемая ширина панелей
- Зависимости между задачами (режим «Зависимость»: предшественник → последователь; циклы запрещены)
- Настройка видимости и порядка колонок
- Экспорт в **XLSX**, импорт / экспорт JSON, встроенный редактор JSON, drag-and-drop `.json` в окно
- Печать (`window.print`)
- Локаль и подписи интерфейса на русском

## Быстрый старт

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Приложение откроется на адресе, который покажет Vite (обычно `http://localhost:5173`).

### Скрипты

| Команда           | Описание                           |
|-------------------|------------------------------------|
| `npm run dev`     | Режим разработки с HMR             |
| `npm run build`   | Проверка типов и production-сборка |
| `npm run preview` | Просмотр собранного `dist`         |
| `npm run lint`    | ESLint                             |

## Формат данных

Документ графика — JSON-объект `GanttData` (тип в `entities/task`):

```json
{
  "meta": {
    "title": "План",
    "subtitle": "График выпуска проектной документации"
  },
  "columns": [
    { "id": "c1", "title": "Критичность срыва сроков", "hidden": true },
    { "id": "c2", "title": "Отдел", "hidden": false },
    { "id": "c3", "title": "Шифр", "hidden": false }
  ],
  "tasks": [
    {
      "id": "task-1",
      "name": "Площадка",
      "kind": "site",
      "start": "2026-08-25",
      "end": "2026-09-06",
      "fields": ["", "", "", "", "", "", "", "", "", ""],
      "collapsed": false,
      "dependsOn": [],
      "children": []
    }
  ]
}
```

| Поле задачи     | Описание                                                                 |
|-----------------|--------------------------------------------------------------------------|
| `id`            | Уникальный идентификатор                                                 |
| `name`          | Название / тип карточки                                                  |
| `kind`          | Тип для цвета строки: `site`, `object`, `stage`, `dept`, `book`, `set`, `assignment` |
| `start` / `end` | Даты в формате `YYYY-MM-DD`                                              |
| `fields`        | Значения пользовательских колонок (до 10)                                |
| `dependsOn`     | Массив `id` предшественников                                             |
| `children`      | Вложенные задачи                                                         |
| `collapsed`     | Свёрнута ли группа в таблице                                             |

Фиксированные колонки таблицы: фактические даты начала и окончания, длительность (вычисляется), тип карточки TDMS. Пользовательские поля по умолчанию: отдел и шифр; «Критичность срыва сроков» скрыта и включается в «Колонки».

При импорте данные нормализуются: недостающие поля подставляются значениями по умолчанию.

Демо-набор (`src/entities/task/mocks/sample.ts`) — пример иерархии площадка / объект / стадия / отдел / книга-том / комплект.

## Структура `src` (FSD)

Импорты идут только вниз по слоям: `app → pages → widgets → features → entities → shared`.  
Слайс экспортирует публичный API через `index.ts`. Алиас `@/*` указывает на `src/*`.

```
src/
├── main.tsx                         # Точка входа: шрифты, стили, render
├── app/
│   ├── App.tsx                      # Корневой shell → страница
│   ├── providers/                   # ConfigProvider (тема, ru_RU, dayjs locale)
│   └── styles/index.css             # Глобальные стили
├── pages/
│   └── gantt-page/                  # Состояние документа и оркестрация экрана
├── widgets/
│   ├── gantt-toolbar/               # Контрольная панель: экспорт, период, вид, zoom
│   ├── gantt-workspace/             # Таблица + splitter + таймлайн, sync scroll
│   ├── task-table/                  # Левая таблица
│   └── gantt-timeline/              # Правая шкала (бары, связи, геометрия)
├── features/
│   ├── column-settings/             # Видимость / порядок колонок
│   ├── link-tasks/                  # Режим зависимостей
│   └── import-export/               # JSON, XLSX, редактор JSON
├── entities/
│   └── task/                        # GanttData / Task, дерево, normalize, sample
└── shared/
    ├── config/                      # Тема Ant Design, константы, ViewMode
    ├── lib/dates/                   # Дата-хелперы
    └── ui/splitter/                 # Разделитель панелей
```

## Использование

1. **Экспорт** — скачать текущий план в Excel (`.xlsx`). JSON: кнопки «Импорт JSON» / «JSON» или перетаскивание `.json` в окно.
2. **Период** — ограничить видимый диапазон шкалы. Кнопка обновления возвращает период по датам задач.
3. **План: Все / Только таблица / Только диаграмма** — переключение раскладки рабочей области.
4. **Группа** / **Задача** — добавить элементы верхнего уровня; у строки — дочерняя задача.
5. **Зависимость** — включить режим, кликнуть предшественника, затем последователя (повторный выбор той же пары снимает связь). `Esc` отменяет режим.
6. **Колонки** — показать / скрыть фиксированные и пользовательские поля. Порядок меняется перетаскиванием заголовков.
7. **Масштаб** — ширина ячейки шкалы.
